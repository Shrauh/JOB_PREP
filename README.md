## 🚀 How to Run This Project in Android Studio

### Step 1: Create a New Flutter Project
```bash
flutter create interview_prep_app
cd interview_prep_app
```

### Step 2: Replace Files
Copy the provided files into your project:
- Replace `lib/main.dart` with the provided `main.dart`
- Replace `pubspec.yaml` with the provided `pubspec.yaml`

### Step 3: Run the App
```bash
flutter pub get
flutter run
```
OR click the **Run** button ▶ in Android Studio.
